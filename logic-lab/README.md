# 数字逻辑实验台

交互式门级数字逻辑仿真器，纯前端（HTML/CSS/JS），零运行时依赖。

## 运行

直接用浏览器打开 `index.html` 即可（无需构建）；或：

```bash
npm start          # python3 -m http.server 8000 → http://localhost:8000
```

## 功能

- **元件**：输入（开关）、输出（指示灯）、与门、或门、非门、异或门、时钟。左侧面板点击放置，画布上拖动移动。
- **连线**：从端口圆点拉线到另一端口（出→入）。允许一个输出扇出到多个输入；允许同一输入端口挂多条线（用于演示冲突检测）。`Delete` 删除选中的元件或连线，`Esc` 取消连线。
- **仿真**：三值逻辑 `0 / 1 / X`。未连接的输入按未知 `X` 处理并沿链路传播（如 `AND(1,X)=X`、`AND(0,X)=0`）。
- **时钟**：点击时钟元件启停；顶栏滑杆全局调速（50ms–2s），选中单个时钟还可在右侧栏单独调速。顶部「运行」开关启动/停止仿真节拍。
- **非法接线检测**：
  - *重复驱动*：同一网络被多个输出端口驱动时，错误面板列出具体元件（如 `U1.out、U2.out`），相关元件红色高亮，该网络电平复位为 `X`，杜绝错误结果。
  - *组合环路*：基于强连通分量检测环路（含自环），标出环路上全部元件并将其输出置 `X`；断开环路后自动恢复。
- **实时重算**：任何移动、增删、改接都会触发全量重算，输出绝不残留旧电平。
- **真值表**：勾选参与枚举的输入集合，一键生成全部输出元件的真值表；`X` 单元格单独标注，电路有错误时给出警告。生成后恢复输入原电平。

## 电平着色

绿色=高电平 1，灰色=低电平 0，橙色虚线=未知 X，红色虚线=重复驱动冲突。

## 测试

```bash
npm test           # 引擎测试（25 例）+ jsdom UI 冒烟测试（23 项）
npm run test:engine   # 仅引擎：各门真值、X 传播、扇出、冲突、环路、时钟、重算、真值表
npm run test:ui       # 仅 UI 冒烟（需先 npm install 安装 devDependency jsdom）
```

## 结构

```
index.html   页面骨架
style.css    样式
engine.js    仿真引擎（UMD，浏览器/Node 通用）：网络构建、三值求值、
             冲突检测、Tarjan SCC 环路检测、拓扑排序求值、真值表生成
app.js       交互层：SVG 渲染、拖动、连线、运行节拍、真值表弹窗
test/        引擎验收测试 + jsdom UI 冒烟测试
```
